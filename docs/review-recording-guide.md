# Crew Plus review — recording guide and checklist

The review is a recorded ~5-minute video addressed to the PARENT about the
child (AMENDMENT-1 §3). Not a live call, never child-facing; parents may
choose to watch it with their child. You see the child's progress snapshot
only: crew name, year group, the same dashboards the parent sees.

## The shape (five minutes, three beats)

1. **What's going well** — praise the METHOD, never the child ("she tracks
   the letter jumps systematically", never "she's clever"). Ground every
   claim in the dashboard you both see.
2. **One focus for the month** — one, singular. Name the question type and
   what "getting there" looks like in the data.
3. **One thing to try at home** — concrete, small, from the same playbook as
   the weekly email's "one thing".

## The checklist (attest per recording; failing = re-record, not edit)

- [ ] Strengths are method-praised and dashboard-grounded
- [ ] Exactly one focus; exactly one at-home suggestion
- [ ] No prediction of any result, score, or outcome (L1 — includes
      "on track for", "should pass", "likely to")
- [ ] No comparison to any other child, named or statistical
- [ ] No urgency language; the register is the parent copy register for the
      child's current intensity column (Addendum D §2)
- [ ] Nothing discussed beyond the learning snapshot (S3 spirit: the review
      discusses the work, never the child's life)

## Release flow (the DSL/admin spot-check — runbook)

Recorder marks RECORDED with the attestation → a DIFFERENT admin/DSL
spot-checks against this checklist → RELEASED to Parent HQ + email link, or
returned for re-record. Spot-check sampling may be 100% at launch and relax
with evidence; the recorder can never release their own work. Retention:
videos deleted 12 months after the subscription ends (DPIA §10c).

An unfulfilled review month auto-credits £15 without being asked — the
machinery runs monthly (`/api/jobs/plus-credit`); never wait for a complaint.
